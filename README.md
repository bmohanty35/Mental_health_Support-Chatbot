🚀 Excited to Share My Latest Project: Production-Ready Mental Health Support Chatbot using Gemini GenAI & AWS EC2

I recently built and deployed a production-ready, domain-specific Mental Health Support Chatbot powered by Google Gemini GenAI API and hosted on an AWS EC2 instance, as part of my internship at Innomatics Research Labs.

The goal of this project was to move beyond a simple chatbot demo and implement a real-world GenAI system with clean architecture, modular design, secure configuration, and scalable deployment.

🔹 Key Features

Domain-specific mental health support with empathetic and safe responses
✅ Multi-turn conversational memory (maintains context across user interactions)
✅ Session-based memory management for personalized conversations
Advanced prompt engineering with safety guardrails
Modular backend architecture (API layer, prompt manager, memory module)
Secure API key management using environment variables
Interactive Streamlit chat-style UI
Deployed on AWS EC2 with public access

🔹 Tech Stack
Python | Google Gemini GenAI API | Streamlit | AWS EC2 | dotenv | Modular Clean Architecture
